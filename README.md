# Qalaciq STEM

Небольшой сайт школьной STEM-команды: YouTube-канал и 10 безопасных демонстрационных экспериментов.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Через несколько минут сайт будет доступен по адресу `https://jsjgksujsl-a11y.github.io/qalaciq-stem/`.

Кнопка YouTube ведёт на канал Qalaciq STEM. Новые ролики можно смотреть на канале; на этой версии сайта они автоматически не отображаются.
